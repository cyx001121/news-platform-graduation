# GitHub 上传整理说明

本版本根据提供的 `manager(1).zip` 整理，面向源码展示。日文首页为根目录的 `README.md`。

## 已做的调整

1. 保留 Spring Boot 后端、Vue 前端、界面静态资源和两套依赖清单及锁文件。
2. 排除两处 `node_modules/`。依赖可由根目录与 `vue/` 内各自的 `npm ci` 安装。
3. 排除原始 `files/` 内的 49 个运行时上传图片，不把这些业务内容当成项目演示截图。
4. 将数据库用户名和密码改为环境变量 `DB_USERNAME`、`DB_PASSWORD`，并允许通过 `DB_URL` 覆盖连接地址。密码没有默认值，运行前必须设置。
5. 将页脚中原有的联系邮箱和电话号码改成示例信息。
6. 将生产构建配置里的不完整 API 地址 `http://:9090` 改为本地验证地址 `http://localhost:9090`。
7. 删除 POM 中旧的 HTTP Maven 镜像配置，使用 Maven 默认仓库配置；依赖版本保持不变。
8. 添加 `.gitignore`、`.gitattributes`、日文 README 和本说明。

没有修改 Java 业务逻辑，也没有补写未经确认的数据库结构。项目中原有的模板和依赖来源不能仅从源码判断，因此没有添加“全部独立开发”等声明或新的开源许可证。

## 检查范围

- 检查源文件结构、依赖清单、配置文件、路由、Controller/Service/Mapper 的关键逻辑。
- 对文本文件搜索硬编码凭据、私钥、常见令牌格式和联系方式；发现的数据库密码已从交付版本中移除。
- 这不是完整的安全审计，也不能证明所有敏感内容或缺陷都已排除。
- GitHub 上传文件只包含整理后的项目，原压缩包中的依赖和运行时上传图片不进入仓库。

## 尚缺的材料

原始压缩包中未发现数据库建表 SQL。实体类和 Mapper 能辅助分析数据库结构，但不能证明原表的字段类型、索引、约束、默认值与初始数据，因此本版本没有根据推测生成一份声称“原始”的 SQL。

如需让公司完整运行项目，后续需要补充从原数据库导出的结构文件，以及经过脱敏且可分享的演示数据。
